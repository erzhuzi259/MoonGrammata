# Changelog

All notable changes follow Keep a Changelog. The project uses semantic
versioning after its first published release.

## [0.1.1] - 2026-10-01

- Bound independent replay records by the configured failure budget, with regression coverage.
- Verify with moonc 0.10.14 and keep CI strict for all but two known migration warnings.

## [0.1.0] - 2026-09-18

### Added

- Composable grammar model with recursive reference validation.
- Reachability, nullability, productivity, recursion, and minimum-cost analysis.
- Depth-, node-, byte-, and repeat-bounded derivation-tree generation.
- Six structure-preserving mutation strategies and compatible subtree crossover.
- Target features, feedback signatures, corpus admission, and energy scheduling.
- Failure-fingerprint reduction and versioned deterministic replay JSON.
- Differential, metamorphic, and agreement oracles.
- Synchronous campaign runner with Markdown and JSON evidence reports.
- Expression, binary TLV, and state operation sequence examples.
- Native smoke CLI.
- Cross-platform CI, release evidence, and a reproducible strategy comparison.
