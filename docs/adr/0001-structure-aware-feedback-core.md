# Structure-aware feedback is the product boundary

MoonGrammata will evolve a persistent corpus of derivation trees using user-reported feature sets, structural mutation, crossover, reduction, and deterministic replay. It will not modify the MoonBit compiler, claim compiler coverage without instrumentation, provide native process sandboxing, or become a general property-testing library; these boundaries keep the project distinct from QuickCheck and make the first release portable across MoonBit backends.
