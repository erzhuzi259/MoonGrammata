# MoonGrammata 0.1 Roadmap

The 0.1 release is organized as independently testable increments so that the Git history records actual engineering progress.

1. Repository, domain language, license, and scope decision.
2. Deterministic pseudo-random generator and bounded sampling utilities.
3. Grammar rule model and reference validation.
4. Nullability, productivity, reachability, and minimum-cost analysis.
5. Budgeted derivation-tree generation.
6. Deterministic rendering and input codecs.
7. Structural deletion and replacement mutations.
8. Repeat-count, numeric-boundary, and dictionary mutations.
9. Compatible-subtree crossover.
10. Target observations, oracles, and failure fingerprints.
11. Corpus admission, deduplication, and metadata.
12. Energy scheduling and feature rarity accounting.
13. Campaign runner, stop limits, and event tracing.
14. Failure-preserving structural reduction.
15. Versioned replay records and deterministic replay.
16. Differential and metamorphic oracle adapters.
17. Expression-language demonstration target.
18. Binary TLV demonstration target.
19. Stateful operation-sequence demonstration target.
20. JSON and Markdown reports plus CLI composition root.
21. Benchmark and strategy-comparison evidence.
22. README, source/provenance notes, CI, and application document.
23. Strict multi-backend verification and acceptance audit.
